2026-10-21 修订。纯静态网站，无需构建，未公开发布。原 PPT 和素材未修改。

## 本地查看
双击 index.html 即可查看。开机动画每个标签页会话只播放一次，可跳过；系统启用减少动态效果时直接显示桌面。

## 使用
- 桌面只有个人简介、视频作品、小红书运营、复盘优化四个文件夹。
- 首页便签保留电话、邮箱及复制操作，右侧是新版手绘头像。
- 点击文件夹打开 PPT 原页。点击原页非交互区域翻到下一页，最后一页再次点击关闭该板块并返回桌面。
- 可用工具栏或键盘左右键翻页。放大后可滚动查看，暂时禁止点击翻页；Esc 退出放大，再次 Esc 关闭窗口。
- 视频页只通过封面、播放按钮或方法论入口抵达。播放控件、返回按钮不会触发翻页。关闭或最小化时暂停，从入口重新打开时从头播放。
- 第18页折线图直接以静态图片展示，无动画。
- 窗口默认最大化打开，支持还原后拖动、最小化和关闭。底部任务栏恢复已有窗口，“开始”展开四个板块入口，右侧小按钮显示桌面。
- 手机完整显示原页，建议横屏或使用“放大”阅读较小文字。

## 部署 GitHub Pages
1. 将本目录内所有文件上传到仓库根目录，包括 assets、index.html、styles.css、app.js、slides.js 和 .nojekyll。不要只上传ZIP。
2. Settings → Pages → Deploy from a branch，选择 main 与 / (root)。
3. 等待部署，打开 GitHub 给出的 Pages 地址。
所有资源为相对路径，支持项目子目录。六条完整视频按需加载，不在首页下载。每条视频小于25 MB。

## 文件说明
- index.html：首页和联系方式。
- styles.css：Windows 桌面和响应式样式。

- assets/slides：PowerPoint 导出的高清原页，以及曲线动画底图。
- assets/wallpaper.jpg：用户提供的蓝天草地壁纸。
- assets/identity.png：用户提供的绿色工牌图片，首页用CSS显示左侧人物。
